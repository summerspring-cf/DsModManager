# DsCppModManager 플러그인 제작 가이드 (v0.30)

이 문서는 **모드매니저와 연동되는 모드**를 만드는 방법을 설명합니다.
연동에 링크나 함수 호출은 필요 없습니다 — **모드 폴더 안의 파일 몇 개가 곧 API**입니다.
(Lua 모드와 C++ 모드 모두 동일하게 동작합니다)

## 1. 인식되기 (필수)

`plugins` 폴더(모드매니저 패널 → 플러그인 → 폴더 바로가기)에 아래 구조로 넣으면
패널의 "모드선택"에 자동으로 나타납니다:

```
plugins\
└─ 내모드이름\
   ├─ Scripts\main.lua      ← Lua 모드
   └─ dlls\main.dll         ← C++ 모드 (둘 중 하나면 충분)
```

등록 함수는 없습니다. 폴더 구조만 맞으면 됩니다.

**pak(콘텐츠) 모드도 됩니다 (v0.27).** `.pak` 을 담은 폴더면 인식합니다:

```
plugins\
└─ 내pak모드\
   └─ 무언가_P.pak      ← .pak 하나면 충분 (.ucas/.utoc/.sig 동반 가능)
```

- 켜면 **하드링크**로 연결됩니다(사본 아님). 기본 목적지는 `Content\Paks\~mods\`
  입니다 — 엔진이 에셋 교체용으로 마운트하는 안전한 위치입니다(대부분의 캐릭터·에셋
  `_P` 팩이 여기).
- **블루프린트 로직 모드**(BPModLoaderMod 가 로드하는)만 `[plugin]` 에
  `pak_target=logicmods` 를 적으세요 → `Content\Paks\LogicMods\` 로 갑니다.
  ⚠ 에셋 팩을 LogicMods 에 넣으면 BPModLoaderMod 가 BP 모드로 로드하려다 **크래시**합니다.
- pak 은 게임 시작 때 마운트되므로 **런타임 켬/끔이 없습니다**(재시작 필요).
  `dsruntime.txt` 폴링은 의미가 없으니 구현하지 않아도 됩니다.

**배포 형태는 자유롭습니다** — 매니저가 `plugins` 아래를 10단계까지 훑어
`Scripts`/`dlls` 를 품은 폴더를 찾아냅니다. 그래서 아래도 전부 인식됩니다:

- 사용자가 zip 을 **풀지 않고 그대로** 넣은 경우 → 매니저가 알아서 풉니다
- `<배포판>\Win64\ue4ss\Mods\<내모드>\` 처럼 게임 폴더 구조가 통째로 든 배포판
- UE4SS 를 함께 담은 "with_UE4SS" 배포판 (UE4SS 기본 모드는 목록에서 자동 제외)

**모드는 `plugins\` 한 곳에만 존재합니다 (v0.26~).** 켜면 `Mods\<이름>` 이 생기지만
사본이 아니라 `plugins\<이름>` 을 가리키는 바로가기(정션)입니다. 그래서:

- 모드가 자기 폴더에 쓰는 로그·설정은 전부 `plugins\<이름>\` 에 쌓입니다
- **DLL/스크립트를 갱신할 때 한 곳만 바꾸면 됩니다.** (v0.25 이하에서는 사본이
  따로 있어 양쪽을 다 바꿔야 하는 함정이 있었습니다 — 이제 없습니다)

## 2. 켜기/끄기에 반응하기 (권장)

매니저가 토글할 때 모드 폴더에 파일을 기록합니다:

| 파일 | 의미 | 기록 시점 |
|---|---|---|
| `enabled.txt` (존재/삭제) | **로드 계층** — 다음 게임 시작에 UE4SS가 로드할지 | 토글 시 |
| `dsruntime.txt` (내용 `1`/`0`) | **런타임 계층** — 이미 로드된 모드가 지금 활동할지 | 토글 시 + 게임 시작 시 |

모드는 **자기 폴더의 `dsruntime.txt`만 1초마다 읽으면** 재시작 없는 켬/끔을
지원하게 됩니다. 파일이 없으면 "켜짐"으로 간주하세요. (아래 헬퍼가 다 해줍니다)

## 3. 세부 옵션 제공하기 (선택)

모드 폴더에 `dsplugin.ini`를 넣으면, 모드가 켜졌을 때 매니저 패널에
**옵션 조절 UI**(토글 · 스테퍼 · 콤보박스 · 키 지정 · 색상 · 체크박스 · 버튼 ·
슬라이더)가 자동으로 생깁니다:

```ini
[plugin]
; 선택: 패널 "모드선택"에 표시될 이름 (한글 가능, UTF-8 저장 필수).
; 생략하면 폴더명이 표시됩니다. 파일/폴더 동작은 항상 폴더명 기준이라
; 이름을 바꿔도 설치·켬끔에는 영향이 없습니다.
name=내 모드 한글이름
; 선택: 구형 공용 계약(mods_enabled.txt)의 키. 신규 모드는 생략 가능
runtime_key=mymod

[option:sound]
label=소리 알림
type=bool
default=1

[option:radius]
label=탐지 반경 (m)
type=int
min=20
max=200
step=10
default=60
```

- 섹션 이름 `option:<키>` 의 `<키>`가 저장 파일의 키가 됩니다 (영문/숫자/_, 31자 이내)
- `type`: 아래 8종 중 하나. 생략하면 `bool`

  | `type=` | 컨트롤 | 저장값 |
  |---|---|---|
  | `bool` | 켜기/끄기 토글 | 0 / 1 |
  | `int` | `◀ 값 ▶` 스테퍼 (`min`·`max`·`step`) | 정수 |
  | `int` + `choices=` | 콤보박스(드롭다운) | 0기준 인덱스 |
  | `key` | 키 지정 | 가상키 코드 (0=없음) |
  | `color` | 색 견본 + 팔레트 창 | 0xRRGGBB 정수 |
  | `check` | 체크박스 | 0 / 1 |
  | `button` | 실행 버튼 | 누른 **횟수** |
  | `slider` | 가로 게이지 (`min`·`max`, 0~1000) | 정수 |
- `label`: 패널에 표시될 한국어 라벨 (UTF-8)
- 모드당 최대 **16개** — 화면에 보이는 옵션이 **8개 이상**이면 매니저가 자동으로
  앞 7개만 보여주고 **"펼치기/접기" 행**을 붙입니다 (선언 순서가 곧 우선순위:
  자주 쓰는 옵션을 앞에 선언하세요)

### 콤보박스 (드롭다운, v0.15)

`choices=` 로 항목을 나열하면 스테퍼 대신 **게임 설정창과 동일한 드롭다운**이
생깁니다 (닫힘 알약 + ▼, 호버 카키 하이라이트 + ◆ 마커, 8개 이상은 휠 스크롤):

```ini
[option:foodkind]
label=음식 종류
type=int
choices=아무거나, 체력 회복만, 부활만
default=0
```

- 항목은 쉼표 구분, **최대 10개**, 각 23자 이내 (한글 가능, UTF-8)
- 저장되는 값 = **0부터 시작하는 인덱스** (`choices` 순서 그대로;
  위 예에서 "부활만" 선택 = `foodkind=2`). `min`/`max`/`step` 은 무시됩니다
- `default` 도 인덱스로 적습니다
- 항목이 1개뿐이면 콤보로 취급하지 않고 일반 컨트롤로 돌아갑니다
- 자식 옵션의 `parent_value=` 와 조합하면 "특정 항목을 골랐을 때만 나오는
  하위 옵션"이 됩니다 (인덱스로 비교)


### 키 바인딩 (v0.28)

`type=key` 로 선언하면 **키를 눌러 지정하는** 컨트롤이 생깁니다.
저장값은 **윈도우 가상키 코드(정수)** 입니다.

```ini
[option:togglekey]
label=표시 켜기/끄기 키
type=key
default=F7
```

- `default` 는 `F7`·`A`·`Space`·`Insert` 처럼 이름으로 적어도 되고 숫자도 됩니다.
  **생략하면 `없음`(0) 으로 시작**합니다 — 게임의 키 변경 UI 관례이니 특별한 이유가
  없으면 생략을 권합니다
- 사용자가 알약을 누르면 "키를 누르세요" 상태가 되고, 다음에 누른 키가 저장됩니다
  (ESC 는 취소, 마우스 좌클릭은 UI 조작이라 잡히지 않습니다)
- **`Delete` 는 해제**로 처리되어 값이 `0`(없음)이 됩니다. 그래서 `Delete` 자체는
  바인딩할 수 없습니다. **모드는 값이 0 이면 "키 없음"으로 다뤄야 합니다**
  (0 을 그대로 `GetAsyncKeyState` 에 넘기지 마세요)
- 모드는 그 정수를 그대로 `GetAsyncKeyState` 등에 쓰면 됩니다:
  `if (GetAsyncKeyState(opts.togglekey) & 0x8000) { ... }`
- Lua 모드는 `dsoptions.txt` 의 정수를 읽어 자체 키 처리와 비교하세요

### 색상 (v0.28)

`type=color` 로 선언하면 **색 견본 + `#RRGGBB`** 컨트롤이 생기고,
누르면 **채도/명도 사각형 · 색조 띠 · 프리셋 팔레트 · HEX 입력**이 있는 창이 열립니다.

```ini
[option:markercolor]
label=마커 색
type=color
default=#FFD60A
```

- 저장값은 **0xRRGGBB 정수**입니다 (`dsoptions.txt` 에는 10진수로 적힙니다)
- 사각형/띠는 **누른 채 끌면** 실시간으로 바뀝니다
- 창이 열린 상태에서 `0-9 A-F` 를 입력하면 HEX 로 직접 지정됩니다(6자리 채우면 적용,
  Backspace 로 지우기). ESC 나 바깥 클릭으로 닫습니다
- 모드에서 쓸 때: `R=(v>>16)&0xFF, G=(v>>8)&0xFF, B=v&0xFF`

### 체크박스 (v0.29)

`type=check` 는 **0/1** 을 네모 체크로 받습니다. `bool` 토글과 값은 같고 생김새만
다릅니다 — 큼직한 켜기/끄기 토글이 과한 자잘한 항목에 쓰세요.

```ini
[option:showtimer]
label=남은 시간 표시
type=check
default=1
```

- `min`/`max`/`step` 은 무시됩니다 (항상 0/1)
- 자식 옵션의 부모로 쓸 수 있습니다 (`parent=showtimer` = 체크됐을 때만 표시)

### 실행 버튼 (v0.29)

`type=button` 은 값을 고르는 컨트롤이 아니라 **한 번 시키는** 컨트롤입니다.
저장값은 **누른 횟수**이고, 누를 때마다 1씩 늘어난 채로 `dsoptions.txt` 에 기록됩니다.

```ini
[option:rescan]
label=상자 다시 탐색
type=button
button=지금 실행       ; (선택) 버튼에 쓸 글자. 생략하면 "실행"
```

- 모드는 **값이 지난번보다 커졌을 때** 한 번 일하고, 그 값을 기억하면 됩니다:

  ```lua
  local last = opts.rescan or 0
  -- 1초 폴링 안에서
  if (opts.rescan or 0) > last then last = opts.rescan; rescan_now() end
  ```

- 그래서 **첫 실행에 저절로 눌린 것처럼 되지 않습니다** (시작 시 값을 기준으로 잡으면 됨)
- `default` 는 적지 마세요 — 0에서 시작하는 게 규약입니다

### 슬라이더 (v0.29)

`type=slider` 는 게임 설정창(음량·감도)과 같은 **가로 게이지**입니다.
누른 순간부터 손잡이가 커서를 따라오고, 오른쪽에 현재 값이 숫자로 붙습니다.

```ini
[option:opacity]
label=오버레이 불투명도
type=slider
min=0
max=100
default=80
```

- 허용 범위는 **0 ~ 1000** 입니다. `min` 은 0 미만으로, `max` 는 1000 초과로
  내려/올려도 매니저가 잘라냅니다. 생략하면 `0~100`
- 저장값은 정수 하나 (`opacity=80`). 소수가 필요하면 1000 배로 받아
  모드에서 나누세요 (`min=0 max=1000` → `v/1000.0`)
- 슬라이더 위에서 좌우로 끌어도 **패널이 위아래로 스크롤되지 않습니다** —
  슬라이더가 그 드래그를 가져갑니다
- 값은 **뗄 때 한 번** 저장됩니다 (끄는 동안 파일이 매 프레임 갱신되지 않음)

### 자식 옵션 (조건부 표시)

옵션에 `parent=<부모키>` 를 넣으면 **부모 옵션이 켜졌을 때만**(bool 기준) 그 아래에
들여쓰기로 나타나는 자식 옵션이 됩니다. 선언하지 않으면 아무 일도 없습니다 —
자식은 모드가 매니페스트에 명시했을 때만 존재합니다.

```ini
[option:autoswap]
label=음식 자동교체
type=bool
default=0

[option:foodkind]
label=음식 종류
type=int
min=0
max=2
step=1
default=0
parent=autoswap        ; autoswap 이 켜졌을 때만 표시
;parent_value=2        ; (선택) 부모가 정확히 이 값일 때만 표시 -- int 부모용
```

- 조건: `parent_value` 를 지정하면 "부모 == 그 값", 생략하면 "부모 ≠ 0(켜짐)"
- 자식 섹션은 부모 **바로 다음에** 선언하세요 (표시 순서 = 선언 순서)
- 부모 값을 바꾸면 패널이 즉시 갱신되어 자식이 나타나거나 사라집니다
- 자식의 자식(2단 이상)도 가능하며, 값은 표시 여부와 무관하게 dsoptions.txt 에 항상 저장됩니다

사용자가 값을 바꾸면 매니저가 모드 폴더에 **`dsoptions.txt`** 를 기록합니다:

```
sound=1
radius=80
```

## 4. 모드에서 값 읽기

### Lua 모드 — 동봉된 `dsmm_options.lua` 사용 (권장)

`dsmm_options.lua`를 모드의 `Scripts\` 폴더에 복사한 뒤:

```lua
local mm = require("dsmm_options")

-- 방법 A: 시작 시 1회
local opts = mm.load({ sound = 1, radius = 60 })   -- 기본값과 병합돼 반환
print(opts.radius)

-- 방법 B: 주기 루프에서 (1초 캐시 폴링 -- 켬/끔 + 옵션 동시)
LoopInGameThreadWithDelay(1000, function()
    local enabled, opts = mm.poll({ sound = 1, radius = 60 })
    if not enabled then return end   -- 매니저에서 꺼짐 -> 쉼
    -- opts.sound, opts.radius 사용
end)
```

### C++ 모드 — 파일 두 개만 읽으면 됩니다

```c
// <자기 DLL 폴더>\..\dsoptions.txt 와 ..\dsruntime.txt 를 표준 파일 IO로 읽기
// dsoptions.txt: "key=정수" 줄들 / dsruntime.txt: '1' 또는 '0' 한 글자
```

## 5. 재시작 안내 팝업 요청하기 (선택)

어떤 옵션은 모드 구조상 **게임 재시작 후에만** 적용됩니다. 그 판단은 모드만이
할 수 있으므로, 모드가 신호를 보내면 매니저가 게임식 안내 팝업을 대신 띄워줍니다:

```lua
local mm = require("dsmm_options")

-- 옵션 폴링 중 재시작 필요한 값이 바뀐 것을 감지했다면:
if opts.big_feature ~= applied_big_feature then
    mm.requestRestartPopup()                       -- 기본 문구
    -- mm.requestRestartPopup("전투 방식 변경은 재시작 후 적용됩니다.")  -- 커스텀 문구
end
```

- 원리: 모드 폴더에 `dsnotify.txt` 를 쓰면(내용 = `restart` 또는 커스텀 메시지)
  매니저가 1초 내 감지해 팝업을 띄우고 파일을 지웁니다(1회성)
- 기본 문구는 `『모드 표시명』 변경 사항은 게임 재시작 후 적용됩니다.`
- C++ 모드는 같은 파일을 직접 쓰면 됩니다 (한 줄 fwrite)
- 신호 감지는 타이틀 화면에서 동작합니다 (매니저 활동 구간)

## 5-1. 매니저 표시 언어 따라가기 (v0.40, 선택)

매니저 UI 는 한국어/English 를 지원하고, 현재 언어를 **`Mods\DsCppModManager\dsmmlang.txt`**
("ko" 또는 "en") 에 방송합니다. 모드가 다국어 문구를 갖고 있다면 이 파일을 읽어
매니저와 언어를 맞출 수 있습니다 — 사용자가 매니저에서 언어를 바꾸거나 게임 언어를
바꾸면 2초 안에 갱신됩니다.

```lua
local mm = require("dsmm_options")
local L = (mm.lang() == "en")
    and { found = "Chest found!" }
    or  { found = "상자 발견!" }
```

- 경로는 자기 모드 폴더 기준 `..\DsCppModManager\dsmmlang.txt` 입니다
  (동봉 헬퍼 `mm.lang()` 이 이 계산을 해 줍니다. C++ 은 같은 경로를 fopen)
- 파일이 없으면(구버전 매니저) "ko" 로 간주하세요
- **의무가 아닙니다** — 단일 언어 모드는 그냥 무시하면 됩니다

**패널 라벨을 두 언어로 싣기 (`_en` 변형 키)** — 매니페스트에 영어 변형을 함께
선언하면 매니저가 언어에 맞는 쪽을 골라 그립니다. 패널을 지을 때 고르므로 언어
전환과 **같은 프레임**에 바뀝니다 (파일을 고쳐 갈아끼울 필요가 없습니다):

```ini
[plugin]
name=음식 자동스왑(DsAutoFood)
name_en=Auto Food Swap (DsAutoFood)

[option:slot4kind]
label=음식 종류
label_en=Food Type
choices=아무거나, 체력 회복만, 부활만
choices_en=Anything, HP Recovery Only, Revive Only
```

- 지원 키: `name_en` · `label_en` · `choices_en` · `button_en` (전부 선택 사항)
- ⚠ `choices_en` 은 원본과 **항목 수·순서가 같아야** 합니다 (저장값 = 0기준 인덱스)
- `_en` 이 없으면 원본 값을 그대로 씁니다 — 단일 언어 모드는 아무것도 할 필요 없음

## 6. 동작 규칙 요약

- 옵션 변경은 **즉시 파일에 반영**됩니다. 적용 시점은 모드의 읽기 주기입니다
  (1초 폴링 권장 — 재시작 불필요)
- 처음 켜는 모드(이번 세션 미로드)는 매니저가 "재시작 필요" 팝업을 대신 띄워줍니다
- 값 검증(min/max)은 매니저가 하지만, 모드 쪽에서도 방어적으로 클램프하세요
- `dsplugin.ini` 없이도 모드는 정상 인식·토글됩니다 — 옵션 UI만 안 생길 뿐입니다

## 7. 안전장치와 함께 사는 법 (v0.23~)

매니저는 게임이 켜질 때마다 **게임 업데이트**와 **직전 실행의 크래시**를 확인하고,
둘 중 하나라도 걸리면 **모든 모드를 끕니다**(사용자에게 팝업으로 알림).
모드 제작자가 알아야 할 것:

- 내 모드가 사용자 동의 없이 꺼져 있을 수 있습니다. 정상 상황이니 켜져 있음을
  전제로 설계하지 마세요. 꺼진 목록은 `safemode_last.txt` 에 남습니다.
- 크래시 뒤에는 **직전 실행 이후 마지막으로 로그를 남긴 모드**가 용의자로 지목되어
  팝업에 이름이 뜹니다(확정 원인이 아니라는 단서와 함께). 그러니
  **위험한 작업 직전에 로그 한 줄을 남기면** 사고 원인 추적이 훨씬 쉬워집니다.
- 반대로 **아무 일도 없는데 1초마다 로그를 쓰면** 남의 크래시에 억울하게 지목됩니다.
  주기 로그는 조용히, 상태가 바뀔 때만 남기세요.

### ★ 게임 주소를 코드에 박지 마세요

게임이 패치되면 함수 주소가 전부 밀립니다. 그대로 호출하면 **게임이 즉사**합니다
(2026-08-06 실제 사고). 꼭 써야 한다면 **의존하는 모든 주소**에 대해 코드 바이트
지문을 확인하고, 하나라도 어긋나면 그 기능을 끄세요. 절반만 검사하면
"안전하다는 착각"만 생깁니다 — 그 사고가 정확히 그렇게 났습니다.

# 모드매니저 설명서 (DsCppModManager v0.40)

DragonSword: Awakening 의 **타이틀 메뉴에서 모드를 켜고 끄고 설정하는** 관리 도구입니다.
게임 설정창과 같은 모양·같은 조작감으로 만들어져 있어, 별도로 익힐 것이 없습니다.

- 모드를 **만드는 분**은 이 문서 대신 [PLUGIN_GUIDE.md](PLUGIN_GUIDE.md) 를 보세요.
- 이 문서는 **쓰는 분** 기준입니다.

---

## 1. 설치와 진입

### 설치

`DsCppModManager_<버전>.zip` 을 풀고 `install.bat` 을 더블클릭하면 끝입니다.
(기본 스팀 경로가 아니면 install.bat 아이콘 위로 게임 폴더를 드래그하세요.)

UE4SS 를 별도 설치/실행 한 적 없다면 이 모드에 함께 동봉되어 있으니, UE4SS 를 찾아
추가 설치/실행을 하지 않으셔도 됩니다. 버전 업그레이드를 위해 install.bat 으로
업데이트할 때, UE4SS 가 이미 설치되어 있으면 UE4SS 설치 과정은 건너뜁니다.

수동으로 넣을 때는 두 단계입니다.

1. **UE4SS 가 아직 없을 때만** — zip 안 `UE4SS\` 폴더의 내용물(`dwmapi.dll` 과
   `ue4ss` 폴더)을 아래에 복사합니다. 이미 있다면 건너뛰세요 (덮어쓰지 말 것).

   ```
   <게임>\DS\Binaries\Win64\
   ```

2. `DsCppModManager` 폴더를 통째로 아래에 복사합니다.

   ```
   <게임>\DS\Binaries\Win64\ue4ss\Mods\DsCppModManager\
   ```

`mods.txt` 는 **편집할 필요가 없습니다** — 폴더 안의 `enabled.txt` 만 있으면
UE4SS 가 알아서 모드를 시작합니다.

### 진입

게임을 실행하면 **타이틀 메뉴에 "모드매니저" 항목**이 생깁니다. 클릭하면 설정창
스타일의 패널이 열립니다.

> 인게임(ESC 메뉴)에서의 진입은 아직 지원하지 않습니다. 타이틀 화면에서만 열립니다.

```
│                                                          │
│  기본                                                     │  ← 여기부터 스크롤 영역
│  │ 모드 버전                              [  v0.40  ]     │
│  │ 플러그인                            [ 폴더 바로가기 ]   │
│  │ 언어(Language)                    [ 한국어(Korean) ▼ ]  │
│                                                          │

│  │    4번 음식 자동등록                [ 끄기 │ 켜기 ]    │

```

- **제목줄·탭·하단 줄은 고정**이고, 그 사이 내용만 스크롤됩니다.
- 스크롤은 **마우스 휠**과 **빈 곳을 눌러 위아래로 끌기** 두 가지로 됩니다.
- **스크롤바는 평소에 숨어 있다가** 스크롤하는 동안만 나타나고 **1초 뒤 사라집니다**.
- 패널이 열려 있는 동안 뒤쪽 화면은 클릭을 받지 않습니다(모달).

> 버튼·토글은 **누른 자리에서 떼야** 실행됩니다. 누른 채 끌면 스크롤로 처리되고
> 클릭은 취소됩니다 — 그래서 목록 어디를 잡고 끌어도 스크롤이 됩니다.

## 3. 모드 탭

### 기본

| 항목 | 설명 |
|---|---|
| 모드 버전 | 지금 **게임에서 실행 중인** 매니저 버전. 새로 설치했는데 숫자가 그대로면 DLL 이 교체되지 않은 것입니다 (→ 8장) |
| 플러그인 | 클릭하면 모드를 넣는 `plugins` 폴더가 탐색기로 열립니다 |
| 언어(Language) | **매니저 자체 UI 의 언어**입니다 (한국어 / English). 게임 언어 설정을 따라 자동으로 정해지고(한국어 = 한국어, 그 외 = English), **게임 언어를 바꾸면 매니저도 따라갑니다**. 여기서 직접 고른 선택은 게임 언어를 다시 바꾸기 전까지 유지됩니다. 지원하는 모드는 매니저의 언어를 따라 자기 문구도 바꿉니다. ※ 각 모드의 옵션 이름은 그 모드 제작자가 쓴 언어로 나옵니다 |

### 모드선택

`plugins` 폴더에서 발견된 모드가 줄줄이 나옵니다. 등록 절차는 없고 **폴더 구조만
맞으면 자동으로 인식**됩니다:

```
plugins\
└─ 내모드이름\
   ├─ Scripts\main.lua    ← Lua 모드
   └─ dlls\main.dll       ← C++ 모드  (둘 중 하나면 충분)
```

이름은 모드가 `dsplugin.ini` 에 한글 이름을 적어두면 그 이름으로, 없으면 폴더명으로
표시됩니다.

### 켜기 / 끄기 — 두 겹으로 동작합니다

| 겹 | 파일 | 적용 시점 |
|---|---|---|
| 로드 계층 | `enabled.txt` (있으면 켜짐) · `mods.txt` | **게임 재시작 후** — UE4SS 가 모드를 아예 불러올지 |
| 런타임 계층 | `dsruntime.txt` (`1`/`0`) | **즉시** — 이미 불러온 모드가 지금 활동할지 |

매니저는 토글할 때 두 파일을 **함께** 씁니다. 그래서:

- 이미 이번 세션에 로드된 모드 → **끄면 즉시** 조용해집니다 (모드가 1초 폴링을
  지원하는 경우)
- 이번에 로드되지 않은 모드를 켤 때 → **"재시작이 필요합니다" 팝업**이 뜹니다.
  파일은 이미 켜진 상태로 기록됐으니, 다음 실행 때 자동으로 켜집니다.

> 상태의 정본은 이 파일들입니다. 손으로 고쳐도 다음 시작 때 매니저가 정합시키므로,
> **끄고 켜는 것은 반드시 매니저 UI 에서** 하세요.

## 4. 세부 옵션

모드가 옵션을 선언했다면, 그 모드를 **켰을 때** 아래에 들여쓰기된 옵션 줄이 붙습니다.
한 모드가 **최대 16개**까지 선언할 수 있고, 컨트롤은 여덟 가지입니다.

| 컨트롤 | 생김새 | 조작 |
|---|---|---|
| 켜기/끄기 토글 | `[ 끄기 │ 켜기 ]` | 원하는 쪽을 클릭 (선택된 쪽이 카키색) |
| 숫자 스테퍼 | `[ ◀  60  ▶ ]` | ◀ ▶ 를 클릭해 정해진 폭만큼 증감 |
| 콤보박스 | `[ 체력 회복만   ▼ ]` | 클릭 → 목록이 아래로 펼쳐짐 → 항목 클릭 |
| 키 지정 | `[ F7 ]` | 클릭 → "키를 누르세요" → 원하는 키를 누름 (Delete 해제 · ESC 취소) |
| 색상 | `[ ■ #FFD60A ]` | 클릭 → 색상 선택창 (팔레트·그라데이션·HEX 입력) |
| 체크박스 | `[✓]` | 클릭할 때마다 켬/끔 (값은 토글과 같은 0/1) |
| 실행 버튼 | `[ 지금 실행 ]` | 클릭하면 모드가 그 일을 한 번 합니다 |
| 슬라이더 | `●━━━━━━━  400` | 손잡이를 끌거나, 원하는 지점을 클릭 |

**콤보박스 조작**
- 클릭하면 알약 테두리가 밝아지고(포커스) 목록이 펼쳐집니다. 아래 공간이 모자라면
  **위쪽으로 펼쳐집니다** — 목록이 화면 밖으로 나가지 않습니다.
- 마우스를 올린 항목이 카키색으로 강조되고 오른쪽에 ◆ 표시가 붙습니다.
- 항목이 많아 다 안 들어가면 **휠 또는 끌기**로 목록을 스크롤합니다
  (스크롤바는 스크롤할 때만 잠깐 보입니다).
- **바깥을 클릭하거나 ESC** 를 누르면 고르지 않고 닫힙니다.

**키 지정 조작**
- 알약을 클릭하면 `키를 누르세요 (Delete 해제 · ESC 취소)` 로 바뀝니다.
  그 상태에서 원하는 키를 누르면 그 키가 저장됩니다.
- **`Delete` = 지정 해제** (`없음` 으로 되돌림). 잘못 눌렀거나 아직 정하고 싶지
  않을 때 쓰세요. `ESC` = 취소(원래 값 유지).
- 마우스 좌클릭은 UI 조작이라 지정되지 않습니다(우클릭·휠클릭은 됩니다).

**체크박스 조작**
- 네모를 클릭하면 켜짐(카키 채움 + ✓)과 꺼짐(빈 네모)이 번갈아 바뀝니다.
- 켜기/끄기 토글과 **값이 같습니다**(0/1). 자잘한 항목에 쓰이는 작은 형태일 뿐입니다.

**실행 버튼 조작**
- 값을 고르는 게 아니라 **한 번 시키는** 컨트롤입니다 (예: "지금 다시 탐색").
- 누른 순간 모드에 "한 번 해라" 가 전달되고, 버튼 글자는 그대로 있습니다.
- 여러 번 눌러도 됩니다 — 누른 만큼 모드가 그만큼 일합니다.

**슬라이더 조작**
- **누른 지점으로 손잡이가 곧바로 옵니다.** 누른 채 좌우로 끌면 따라옵니다.
- 오른쪽 숫자가 실시간으로 바뀌고, **손을 떼는 순간 저장**됩니다.
- 슬라이더 위에서 좌우로 끌어도 **화면이 위아래로 스크롤되지 않습니다**
  (그 드래그는 슬라이더가 가져갑니다). 목록을 스크롤하려면 슬라이더 바깥을 잡으세요.
- 값의 범위는 모드가 정합니다 (매니저가 허용하는 최대 범위는 **0 ~ 1000**).

**색상 조작**
- 알약을 클릭하면 선택창이 열립니다: 위쪽 **사각형**(채도·명도), 아래 **색조 띠**,
  **프리셋 12색**, 아래에 미리보기와 `#RRGGBB`.
- 사각형과 띠는 **누른 채 끌면** 실시간으로 바뀝니다(그림판처럼).
- 창이 열린 상태에서 `0-9 A-F` 를 입력하면 **HEX 로 직접** 지정됩니다.
  6자리를 채우면 바로 적용되고, `Backspace` 로 지웁니다.
- `ESC` 나 창 바깥 클릭으로 닫습니다. 값은 고르는 즉시 저장됩니다.

**값이 저장되는 시점** — 바꾸는 즉시 파일(`dsoptions.txt`)에 기록됩니다.
실제로 반영되는 시점은 모드가 그 파일을 읽는 주기(보통 1초)입니다.
재시작이 필요한 옵션이라면 **모드가 직접 판단해** 안내 팝업을 띄웁니다.

### 조건부(자식) 옵션

모드가 그렇게 선언했다면, 어떤 옵션을 켰을 때만 그 아래에 **한 단 더 들여쓴 옵션**이
나타납니다. 부모를 끄면 자식은 사라지지만 **값은 보존**되어, 다시 켜면 그대로입니다.

### 펼치기 / 접기

옵션이 많은 모드는 화면이 너무 길어지지 않도록 자동으로 접힙니다.

- 보이는 옵션이 **8개 이상**이면 앞 7개만 표시하고 `펼치기 ▼ (옵션 N개 더)` 줄이 붙습니다.
- 그 줄을 **클릭**하면 전부 펼쳐지고, `접기 ▲` 로 바뀝니다.
- 펼친 상태는 게임을 끄기 전까지 기억됩니다 (패널을 닫았다 열어도 유지).
- 접혀서 안 보이는 옵션도 **값은 그대로 살아 있습니다** (표시만 생략).

> 펼치기/접기 줄은 **누를 때가 아니라 뗄 때** 동작합니다. 스크롤하려고 그 자리를
> 누른 채 끌어도 접히지 않습니다. 누른 뒤 다른 곳에서 떼면 취소됩니다.

## 5. 순서 탭

모드가 표시되는 **순서를 직접 정하는 곳**입니다. 여기서 정한 순서는 모드 탭의
"모드선택" 목록에도 그대로 적용됩니다.

**조작**

1. 순서 탭을 엽니다. 모드들이 `≡ 모드이름` 형태로 나열됩니다.
2. 옮기고 싶은 줄을 **누른 채로** 위나 아래로 끕니다. 잡힌 줄은 밝게 표시되고,
   지나가는 자리에 맞춰 목록이 실시간으로 재배열됩니다.
3. **버튼을 떼면** 그 순서가 저장됩니다.
4. 끌던 중 **ESC** 를 누르면 그 자리에서 드래그만 끝납니다 (패널은 닫히지 않음).

순서는 `Mods\DsCppModManager\dsorder.txt` 에 폴더명 한 줄씩 저장됩니다.
파일에 적힌 모드가 그 순서대로 앞에 오고, 새로 추가된 모드는 뒤에 붙습니다.
파일을 지우면 발견된 순서(대개 이름순)로 돌아갑니다.

## 6. 안내 팝업

게임의 기본 팝업과 같은 모양으로 아래 경우에 뜹니다. `확인` 또는 `ESC` 로 닫습니다.

| 경우 | 문구 |
|---|---|
| 이번 세션에 로드되지 않은 모드를 켰을 때 | 모드 적용을 위해 게임 재시작이 필요합니다. |
| 모드가 직접 요청했을 때 | 『모드이름』 변경 사항은 게임 재시작 후 적용됩니다. (모드가 지정한 문구) |
| 게임이 업데이트됐을 때 | 게임이 업데이트되어 안전을 위해 모드 N개를 껐습니다. |
| 직전 실행이 크래시로 끝났을 때 | 직전 실행이 비정상 종료되어 모드 N개를 껐습니다. + 마지막으로 기록을 남긴 모드 |

두 번째는 **모드가 판단하고 매니저는 대신 띄워주기만** 합니다. 어떤 설정이 재시작을
요구하는지는 모드만 알기 때문입니다.

뜬 문구는 전부 `dlls\cppmm_log.txt` 에도 기록되니, 팝업을 닫아 버려도 나중에 확인할 수 있습니다.

## 6-1. 안전장치 — 게임이 튕겼을 때 (v0.23~)

모드가 게임을 죽이면 **메인 메뉴에 닿기도 전에** 꺼지는 일이 생깁니다. 그러면 매니저를
열 수 없어 모드를 끌 방법이 없습니다. 그래서 매니저는 게임이 켜질 때마다 두 가지를 봅니다.

| 감지 | 어떻게 | 조치 |
|---|---|---|
| 게임 업데이트 | 게임 실행파일이 바뀌었는지 | 모드를 전부 끕니다 |
| 직전 실행 크래시 | 지난 실행 이후 생긴 크래시 기록이 있는지 | 모드를 전부 끄고, **마지막으로 기록을 남긴 모드**를 알려줍니다 |

- 꺼진 모드 목록은 `safemode_last.txt` 에 남습니다. 매니저에서 다시 켜면 됩니다.
- 게임 업데이트 직후에는 모드가 새 버전에 맞는지 확인한 뒤 켜세요. 오래된 모드가
  게임을 죽이는 가장 흔한 경우입니다.
- ※ **"마지막으로 기록을 남긴 모드"는 확정된 원인이 아닙니다.** 기록이 잦은 모드가
  뽑힐 수 있으니 참고용으로만 보세요. 게임 자체 문제였다면 그냥 다시 켜면 됩니다.
- 켜져 있던 모드가 없으면 아무 일도 하지 않습니다.
- 매니저를 처음 설치한 다음 첫 실행은 기준값만 기록합니다(비교 대상이 없으므로).
  보호는 그다음 실행부터 작동합니다.

### 게임패드 (v0.40)

패드가 연결되어 있으면 탭 옆에 `LB`/`RB` 칩과 하단에 `(A) 선택 · (B) 닫기` 힌트가 붙습니다.

| 입력 | 동작 |
|---|---|
| 십자키 / 왼스틱 위·아래 | 행 선택 이동 (선택된 행에 크림색 테두리, 화면 밖이면 자동 스크롤) |
| 십자키 / 왼스틱 좌·우 | 값 조절 — 토글 끄기/켜기 · 스테퍼 증감 · 콤보 항목 순환 · 슬라이더 (범위의 1/20 씩) |
| A | 실행 — 토글/체크 뒤집기 · 버튼 누르기 · 키 지정 시작 · 색상창 열기 · 펼치기/접기 |
| B | 닫기 (ESC 와 동일 — 패널·드롭다운·색상창·팝업) |
| LB / RB | 모드 탭 ↔ 순서 탭 |
| 순서 탭에서 A | 행 집기 → 위/아래로 옮기기 → 다시 A = 저장 |
| **타이틀 화면에서 Y** | **모드매니저 열기** (패드 사용 중엔 "모드매니저" 라벨 옆에 Y 버튼 아이콘이 붙습니다) |

타이틀 메뉴의 위·아래 순회는 게임이 네 항목(게임시작·이어하기·설정·나가기)을
내부 코드로 고정 순회해서 "모드매니저" 행에는 멈추지 않습니다. 그래서 패드는
**Y 버튼이 정식 진입 경로**입니다. 마우스로는 행을 그냥 클릭하면 됩니다.

## 8. 파일 위치 정리

모두 `<게임>\DS\Binaries\Win64\ue4ss\Mods\` 아래입니다.

### 매니저 폴더 (`DsCppModManager\`)

| 파일 | 내용 |
|---|---|
| `dlls\main.dll` | 매니저 본체 |
| `dlls\cppmm_log.txt` | 동작 기록 (문제 신고 시 이 파일을 첨부) |
| `Assets\*.png` | UI 이미지 (토글·콤보박스·색상 선택기·배경) |
| `enabled.txt` | 이 파일이 있으면 매니저가 켜짐 |
| `dsorder.txt` | 순서 탭에서 정한 모드 순서 |
| `bootstate.txt` | 안전장치 기준값 (게임 버전·지난 실행 시각) |
| `safemode_last.txt` | 안전장치가 끈 모드 목록 |
| `plugins\` | **모드를 넣는 곳** |

### 각 모드 폴더 (`plugins\<모드>\`)

| 파일 | 쓰는 쪽 | 내용 |
|---|---|---|
| `dsplugin.ini` | 모드 제작자 | 표시 이름과 옵션 선언 |
| `dsoptions.txt` | 매니저 → 모드 | 사용자가 정한 옵션 값 |
| `dsruntime.txt` | 매니저 → 모드 | 지금 켜짐(`1`)/꺼짐(`0`) |
| `enabled.txt` | 매니저 | 다음 실행 때 불러올지 |
| `dsnotify.txt` | 모드 → 매니저 | 안내 팝업 요청 (매니저가 읽고 지움) |

### 모드는 `plugins\` 한 곳에만 있습니다 (v0.26~)

모드를 켜면 `Mods\<모드이름>` 이 생기는데, **사본이 아니라 `plugins\<모드이름>` 을
가리키는 바로가기(정션)** 입니다. UE4SS 가 `Mods\` 에서만 모드를 읽기 때문에 필요한
이정표일 뿐, 파일은 `plugins` 에 한 벌만 존재합니다.

- 끄면 그 바로가기는 **사라집니다.** 찌꺼기가 남지 않습니다.
- 설정·로그도 전부 `plugins\<모드>\` 에 쌓입니다. 백업하려면 그 폴더만 챙기면 됩니다.
- 예전 버전(v0.25 이하)은 진짜 복사본을 만들었습니다. 그때 만들어진 폴더가
  `Mods\` 에 남아 있으면 매니저가 **지우지 않고 경고만** 남깁니다(남의 파일이므로).
  그런 폴더는 매니저와 무관하게 로드되니, 정리하려면 직접 지우세요.

## 9. 문제가 생기면

**바꾼 내용이 반영되지 않아요 / 옵션이 다 안 보여요**
패널의 `모드 버전` 값을 확인하세요. 최신 버전 숫자가 아니면 `main.dll` 이 교체되지
않은 것입니다. C++ 모드 DLL 은 **게임이 실행 중이면 파일이 잠겨** 덮어쓰기가 조용히
실패합니다. **게임을 완전히 종료한 뒤** 다시 복사하세요.
(이미지 파일 `Assets\*.png` 은 실행 중에도 교체됩니다.)

**타이틀에 "모드매니저" 항목이 없어요**
- `Mods\DsCppModManager\enabled.txt` 가 있는지 확인
- UE4SS 버전이 다르면 DLL 로드가 거부될 수 있습니다 (게임은 정상 실행되고 모드만 꺼짐).
  이 빌드는 UE4SS 실험 채널 커밋 `c838a8ac` 에서 검증됐습니다.
- `dlls\cppmm_log.txt` 와 `ue4ss\UE4SS.log` 를 확인

**모드가 목록에 안 나와요**
폴더 구조를 확인하세요 — `plugins\<이름>\Scripts\main.lua` 또는
`plugins\<이름>\dlls\main.dll` 중 하나가 있는 폴더여야 합니다.
**`Scripts` 또는 `dlls` 폴더를 품은 폴더 = 모드**이고, 매니저가 `plugins` 아래를
**10단계까지 훑어** 찾아냅니다. 배포판이 게임 폴더째 압축된 형태(8단계)라도
그대로 인식됩니다 (최대 50개 표시):

```
plugins\어떤배포판_with_UE4SS\Win64\ue4ss\Mods\내모드\Scripts\main.lua
                                             └── 이 폴더가 모드로 잡힘
```

### pak(콘텐츠) 모드도 관리합니다 (v0.27)

`.pak` 파일을 담은 폴더도 모드로 인식합니다. 블루프린트 모드·에셋 교체 모드처럼
**게임 콘텐츠를 바꾸는 모드**가 여기 해당합니다.

```
plugins\
└─ 내pak모드\
   ├─ 무언가_P.pak      ← 이것만 있으면 모드로 잡힙니다
   └─ readme.txt        (있어도 무방)
```

- **켜면** 게임의 `Content\Paks\LogicMods\` 에 연결되고, **끄면** 연결만 끊깁니다.
  파일은 `plugins` 에 한 벌만 있습니다(하드링크 방식 — 디스크를 두 배로 쓰지 않습니다).
- **게임을 재시작해야 적용됩니다.** pak 은 게임이 켜질 때 한 번만 읽힙니다.
- 에셋을 교체하는 종류라면 모드 제작자가 `dsplugin.ini` 에 `pak_target=paks` 를
  적어 두면 `Content\Paks\~mods\` 로 갑니다 (기본값은 `LogicMods`).
- `.ucas`·`.utoc`·`.sig` 가 함께 있으면 같이 연결됩니다.
- 같은 이름의 파일이 이미 목적지에 있는데 **우리가 건 것이 아니면 건드리지 않습니다**
  (직접 넣어 두신 pak 을 지우지 않기 위해서입니다).

### zip 을 그대로 넣어도 됩니다 (v0.22)

압축을 풀지 않고 **`.zip` 파일 그대로** `plugins` 폴더에 넣어도 됩니다.
매니저가 게임 실행 중에 알아서 풀어 줍니다 (같은 이름의 폴더로).

```
plugins\내모드_1.0.zip   →   plugins\내모드_1.0\내모드\Scripts\main.lua  (자동)
```

- 푼 뒤에는 위의 깊이 탐색이 모드를 찾아내므로, **zip 을 넣고 게임을 한 번
  재시작하면 목록에 나타납니다.** 이후 켜고 다시 시작하면 적용됩니다.
- 원본 zip 은 지우지 않고 그대로 둡니다. 폴더가 이미 있으면 다시 풀지 않습니다.
- 압축 해제에는 Windows 에 기본으로 있는 `tar` 를 씁니다. 아주 오래된 Windows 라
  없다면 직접 압축을 풀어 주세요 (그 경우 로그에 안내가 남습니다).
- 200MB 가 넘는 zip 은 자동으로 풀지 않습니다.

- 함께 딸려온 `UE4SS.dll`·`dwmapi.dll` 은 **넣어도 무시됩니다**(게임에 이미 있는
  UE4SS 를 씁니다). 신경 쓰지 않아도 됩니다.
- 번들에 UE4SS 기본 모드(BPModLoaderMod, ConsoleEnablerMod 등)가 섞여 있으면
  목록에서 자동으로 제외합니다.
- 같은 이름의 모드가 여러 곳에서 발견되면 **먼저 찾은 것 하나만** 표시합니다.

**모드를 껐는데 계속 동작해요**
- 그 모드가 런타임 켬/끔(`dsruntime.txt`)을 지원하지 않는 경우입니다. 다음 실행부터는
  아예 로드되지 않습니다 — 게임을 재시작하세요.
- 재시작해도 계속 동작한다면 `Mods\<그 모드 이름>` 이 **예전 버전이 만든 복사본**일 수
  있습니다. 폴더 아이콘에 화살표(바로가기 표시)가 없으면 진짜 폴더입니다. 매니저는
  남의 파일을 지우지 않으니, 그 폴더를 직접 지우면 됩니다
  (설정을 남기고 싶다면 먼저 `plugins\` 쪽으로 옮기세요).

**매니저를 지웠는데 모드가 계속 돌아요**
v0.25 이하에서 켠 모드는 `Mods\` 에 복사본이 남아 매니저 없이도 로드됩니다.
위 항목대로 `Mods\<모드>` 폴더들을 직접 지우세요. v0.26 부터는 복사본을 만들지 않으므로
이 문제가 생기지 않습니다.

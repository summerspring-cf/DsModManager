# DsCppModManager — 버전 기록 (정본)

버전 규칙은 저장소 루트 `VERSIONING.md` 를 따른다.
각 판의 실측·사고·설계 근거 전문은 `STATUS.md` 의 해당 절에 있다 — 여기는 **무엇이
바뀌었는지**만 적는다. (최신이 위)

---

## v0.40 — 2026-08-10

**언어**
- 언어 선택(한국어/English) — 매니저 UI 전면 번역, [기본] 탭에 `언어(Language)` 콤보
- 게임 언어 설정(`LanguageText`)을 따라 자동 선택되고, **게임 언어를 바꾸면 매니저도
  2초 안에 따라간다** (콤보로 직접 고른 선택은 게임 언어를 다시 바꾸기 전까지 유지)
- 플러그인용 언어 방송 `dsmmlang.txt` — 지원하는 모드는 매니저와 같은 언어로 문구를
  맞출 수 있다 (`dsmm_options.lua` 의 `mm.lang()`)
- 게임 언어 전환 때 타이틀 메뉴 항목이 공란이 되던 문제 수정 (라벨 키퍼)

**게임패드**
- 타이틀 화면에서 **Y 버튼으로 모드매니저 열기** (패드 사용 중엔 "모드매니저" 옆에
  Y 아이콘 표시). 이 게임의 타이틀 메뉴는 방향 이동이 엔진 네이티브 코드로 4개 항목만
  순회하도록 고정돼 있어 방향키로는 모드매니저에 멈출 수 없다 — 다섯 자료구조와
  네이티브 함수까지 조사해 확인한 뒤 전용 Y 버튼을 진입 경로로 확정했다.
- 패널 전체 패드 조작: 방향키/왼스틱 = 행 이동(크림색 선택 테두리, 게임 설정창과 동일),
  좌/우 = 값 조절(토글·스테퍼·콤보·슬라이더), A = 실행/열기, B = 닫기(ESC 와 동일)
- LB/RB = 모드 ↔ 순서 탭 전환 (탭 옆에 LB/RB 칩 표시)
- 순서 탭: A 로 집고 위/아래로 옮긴 뒤 A 로 놓으면 저장
- 하단에 (A) 선택 · (B) 닫기 힌트 (패드 연결 시)

**표시**
- 모드선택·순서 탭의 각 행에 **모드 종류(Lua / C++ / pak)** 표시
- 옵션 갱신·언어 전환 때 패널이 1초쯤 사라지던 공백 제거
  (새 패널을 먼저 그린 뒤 옛것을 걷는 방식으로 교체)

**게임패드 2차 (라이브 피드백)**
- 패널이 열린 동안 게임이 패드를 함께 처리하던 문제 차단 — 모드 조작 중 게임이
  조용히 종료되던 사고("나가기" 오발)와 B 가 설정창을 열던 문제의 뿌리
- 선택 표시를 행 전체 칠하기 → **외곽선만**으로 (게임 설정창과 동형)
- LB/RB·A/B 를 게임 스타일 **아이콘**으로, 패드를 쓸 때만 표시(키/마 입력 시 즉시 숨김)
- 하단의 "ESC 또는 X 로 닫기 · 버전" 문구 제거
- 드롭다운 패드 내비: A 열기 → 위/아래 항목 이동 → A 선택, B 는 드롭다운만 닫음
- 게임 설정에서 언어를 바꾼 직후 매니저에 바로 들어와도 언어가 맞도록

**동작 수정**
- 게임 창이 앞에 없을 때는 입력을 받지 않음 — 게임 위에 겹친 다른 창(탐색기 등)을
  클릭하면 그 자리의 게임 컨트롤이 눌리던 문제, 다른 창에 타자 치면 키 바인딩에
  잡히던 문제 수정
- 모드가 보낸 안내 팝업에 **발신자(모드 이름) 표시** — 매니저/게임의 말처럼 읽히던
  혼동 제거
- bootstate 에 매니저 버전 기록 — 매니저 업데이트를 게임 패치와 구분해 로그에 남김
- 배경에서 마우스를 뗐을 때 드래그/스크롤 상태가 썩던 문제, 게임 설정 저장 순간
  언어가 한 틱 튀던 문제, 라벨 키퍼의 FText 누수 수정 (리뷰에서 확정된 3건)
